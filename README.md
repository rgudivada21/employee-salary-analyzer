# Employee Salary Analyzer

A Python project to analyze employee salary data using Pandas.

## Features

- Load employee data from CSV
- Average salary
- Highest salary
- Lowest salary
- Department-wise average salary
- Employee count by department
- Top 5 highest paid employees
- Logging
- Unit Testing with Pytest
- GitHub Actions CI

## Project Structure

employee-salary-analyzer/
├── data/
├── src/
├── tests/
├── logs/
├── .github/workflows/
├── README.md
├── requirements.txt
└── .gitignore

## Technologies Used

- Python
- Pandas
- Pytest
- GitHub Actions

## How to Run

```bash
pip install -r requirements.txt
python src/salary_analyzer.py
```

## Run Tests

```bash
pytest
```
