# Employee Salary Analyzer - Interview Questions

## Q1. Explain your project.

Answer:
This project analyzes employee salary data using Python and Pandas. It loads data from a CSV file, calculates salary statistics, generates department-wise reports, and uses logging, unit testing, and GitHub Actions for CI.

---

## Q2. Why did you use a class?

Answer:
To group all salary-related operations into a single reusable object.

---

## Q3. Why did you use Pandas?

Answer:
Pandas makes reading, filtering, grouping, and analyzing tabular data simple and efficient.

---

## Q4. Why did you use try/except?

Answer:
To handle file-reading errors gracefully without crashing the application.

---

## Q5. Why did you use logging instead of print()?

Answer:
Logging stores application events in log files, making debugging easier in real projects.

---

## Q6. What is groupby()?

Answer:
It groups rows based on a column and performs operations like mean(), count(), or sum().

---

## Q7. Why did you use sort_values()?

Answer:
To sort employees by salary and identify the highest-paid employees.

---

## Q8. What is pytest?

Answer:
Pytest is a Python testing framework used to verify that the application works correctly.

---

## Q9. What is GitHub Actions?

Answer:
GitHub Actions automatically runs tests whenever code is pushed to the repository.

---

## Q10. What improvements would you make?

Answer:
- Read data from a database
- Build a dashboard
- Add REST APIs
- Deploy the application
